Аккуратная сводка здоровья

Утверждён и реализован локально

Задача

Перестроить верхний блок «Здоровье» на вкладке «Сводка», чтобы он стал спокойной иерархичной сводкой, а не набором одинаковых мини-карточек. Задачи и Evening News сохраняют увеличенную высоту из v1.0.14.

Текущее состояние

create_page2 уже уменьшил health-блок до 180 px. Внутри остаются арка готовности, четыре карточки в первой строке и три во второй. Все метрики оформлены одинаковыми контейнерами, поэтому взгляд не понимает, что главное, а тонкие карточки и подписи выглядят тесно.

Убираем визуальные «карточки в карточке» для шести вторичных метрик: оставляем единый плоский блок с тонкими разделителями. Калории исключаем из первого экрана как наименее полезный для вечернего взгляда; данные и контракт Bridge не меняются.

Поведение и данные

  • Готовность остаётся главным индикатором с цветовым статусом.
  • Сон, шаги и пульс — первая строка; ЧСС покоя, ВСР и SpO2 — вторая.
  • Калории не удаляются из Bridge, но не рисуются на сводке.
  • Ни Bridge, ни API, ни OTA-механизм не меняются.

Файлы и шаги

  1. src/ui_dashboard.cpp: заменить создание семи вложенных карточек на главный блок готовности и плоскую сетку из шести метрик.
  2. Сохранить существующие обновления health-данных, переназначив виджеты и убрав вывод калорий.
  3. Пересобрать simulator и esp32-s3-touch-lcd-7b; вручную проверить на устройстве читаемость, вкладку «Сводка» и переходы.

Проверки

  • make -C sim clean all
  • pio run
  • git diff --check
  • На устройстве: данные здоровья обновляются, задачи и новости не перекрываются, переход «День → Сводка → Дом» работает.

Риски и откат

Главный риск — слишком мелкие значения на физическом экране. Откат: вернуть текущую композицию create_page2 отдельным firmware-релизом. Эта задача не меняет данные Bridge и не может повлиять на OTA-протокол.

Открытый вопрос: тёмная тема

Её не включаем в этот релиз. Для фиксированного вечернего расписания Bridge не нужен: HomeDash уже имеет локальное время. Для переключения по астрономическому закату позже добавим sunset/sunrise в weather-контракт Bridge.

Утверждение

После явного «да» реализую именно эту плоскую иерархию, обновлю этот план фактическими проверками и только после отдельного подтверждения выпущу OTA.

Фактический результат

  • В src/ui_dashboard.cpp одинаковые вложенные карточки заменены плоской сеткой 3×2: сон, шаги, пульс, ЧСС покоя, ВСР и SpO2.
  • Готовность осталась единственным крупным визуальным акцентом. Калории сохранены в данных Bridge, но не выводятся на сводке.
  • Пройдены make -C sim clean all, pio run и git diff --check. Размер прошивки: 23.7% RAM, 19.0% flash.
  • OTA v1.0.15 опубликована с firmware.bin. Установка на физический дисплей не запускалась и всё ещё требует отдельного подтверждения готовности устройства.
